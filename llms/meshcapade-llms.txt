# Meshcapade

> Meshcapade builds digital humans. Its technology turns images, video, motion
> capture, measurements or text into anatomically accurate, animation-ready 3D
> avatars built on the SMPL / SMPL-X / SUPR parametric body-model family that
> originated at the Max Planck Institute for Intelligent Systems. Meshcapade
> offers a hosted avatar platform (me.meshcapade.com) and a REST API for
> programmatic avatar creation, alongside open-source body-model libraries and
> DCC integrations for Blender, Maya and Unreal Engine. Customers span fashion,
> robotics, gaming/animation, fitness and scientific research.

## Packages
- [smplcodec (PyPI)](https://pypi.org/project/smplcodec/): Read and write .smpl avatar files. `pip install smplcodec`
- [smpl-rs](https://github.com/Meshcapade/smpl-rs): SMPL functionality built in Rust.
- [SMPL_blender_addon](https://github.com/Meshcapade/SMPL_blender_addon): Edit, reshape and animate SMPL-H/SMPL-X/SUPR bodies in Blender.
- [SMPL_maya_plugin](https://github.com/Meshcapade/SMPL_maya_plugin): SMPL model integration for Maya.
- [mc-unreal](https://github.com/Meshcapade/mc-unreal): Meshcapade support for Unreal Editor.
